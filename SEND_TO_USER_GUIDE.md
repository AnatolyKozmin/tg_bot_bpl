# 📤 Отправка файлов пользователям - Инструкция

## Что это?

Функция для администраторов, позволяющая отправлять файлы или картинки конкретному пользователю по его Telegram ID.

## Как использовать?

### Метод 1: Пошаговый

1. **Отправь команду:**
```
/send_to
```

2. **Введи Telegram ID получателя:**
```
123456789
```

Бот проверит, существует ли пользователь в базе данных и покажет его ФИО (если найден).

3. **Отправь файл:**
- 🖼 Фото (изображение)
- 📄 Документ (PDF, DOC, XLS, etc.)
- 🎥 Видео
- 🎵 Аудио

4. **Добавь подпись (опционально):**
- Введи текст подписи
- Или отправь `/skip` чтобы отправить без подписи

5. **Готово!** Файл отправлен пользователю.

---

### Метод 2: Быстрый (с ID сразу)

Можно указать Telegram ID сразу в команде:

```
/send_to 123456789
```

Бот сразу перейдет к шагу загрузки файла.

---

## Примеры использования

### Отправка картинки с подписью

```
1. /send_to 123456789
2. [Загрузить картинку]
3. Введи текст: "Привет! Вот твоя новая картинка 🎨"
```

### Отправка документа без подписи

```
1. /send_to 987654321
2. [Загрузить PDF файл]
3. /skip
```

---

## Отмена процесса

В любой момент можно отменить процесс командой:
```
/cancel
```

## Поддерживаемые типы файлов

| Тип | Описание | Пример |
|-----|----------|--------|
| 🖼 **Фото** | Изображения (JPG, PNG, etc.) | Картинки, фотографии |
| 📄 **Документ** | Любые файлы | PDF, DOC, XLS, TXT, ZIP |
| 🎥 **Видео** | Видеофайлы | MP4, AVI, MOV |
| 🎵 **Аудио** | Аудиофайлы | MP3, WAV, OGG |

---

## Ограничения

- **Подпись:** Максимум 1024 символа
- **Размер файла:** Зависит от типа (обычно до 50 МБ для обычных файлов, до 20 МБ для фото через бота)

---

## Что делать если ошибка?

### Пользователь не найден в БД

```
⚠️ Пользователь с Telegram ID 123456789 не найден в базе данных.
```

**Решение:** Можно продолжить отправку - файл будет отправлен напрямую по ID (если ID корректен и пользователь не заблокировал бота).

### Ошибка при отправке

```
❌ Ошибка при отправке:
Forbidden: bot was blocked by the user
```

**Возможные причины:**
- Пользователь заблокировал бота
- Неверный Telegram ID
- Проблема с сетью

**Решение:** Проверь правильность Telegram ID или попроси пользователя разблокировать бота.

## Логирование

Все отправки логируются:
```
✅ File sent to user: telegram_id=123456789, type=photo, admin=987654321
```

Можно отслеживать в логах бота (`bot.log`) для аудита.

## Технические детали

- **Состояния FSM:** `SendToUserStates` (enter_telegram_id, upload_file, enter_caption)
- **Проверка админа:** `is_admin(user_id)`
- **Поддержка типов:** photo, document, video, audio
- **Отправка:** Через `bot.send_photo()`, `bot.send_document()`, etc.

## FAQ

**Q: Можно отправить несколько файлов одновременно?**  
A: Нет, каждый файл отправляется отдельно. Используй `/send_to` повторно для каждого файла.

**Q: Можно отправить файл пользователю, которого нет в БД?**  
A: Да, если ты знаешь его Telegram ID. Файл будет отправлен напрямую.

**Q: Можно использовать Markdown в подписи?**  
A: Да, поддерживается базовое форматирование (`**жирный**`, `*курсив*`, `` `код` ``).

**Q: Получит ли пользователь уведомление?**  
A: Да, как обычное сообщение от бота.
