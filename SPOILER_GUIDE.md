# 🔒 Руководство по использованию скрытого текста (спойлеров)

## Что такое спойлеры?

Спойлеры (скрытый текст) - это способ скрыть часть сообщения, которую пользователь может открыть нажатием. Текст будет отображаться как затемненная область, которую нужно нажать, чтобы увидеть содержимое.

## Как использовать спойлеры

### Базовый синтаксис

Просто оберни текст в двойные вертикальные черты:
```
||скрытый текст||
```

### Пример 1: Простой спойлер

**Текст для рассылки:**
```
Привет! Это обычный текст, а вот ||это скрыто||
```

**Как будет выглядеть у получателя:**
- "Привет! Это обычный текст, а вот [затемненная область]"
- При нажатии на затемненную область откроется текст "это скрыто"

### Пример 2: Секретная информация

**Текст для рассылки:**
```
🎉 Важное объявление!

Дата мероприятия: 15 декабря
Время: 18:00
Место: ||Главный корпус, 3 этаж, аудитория 301||

Не забудьте билеты!
```

**Как будет выглядеть:**
- Вся информация видна, кроме места проведения
- Место будет скрыто и откроется при нажатии

### Пример 3: Несколько спойлеров

**Текст для рассылки:**
```
📋 Программа мероприятия:

1. Регистрация: ||9:00 - 10:00||
2. Открытие: ||10:00 - 10:30||
3. Основная часть: ||10:30 - 14:00||
4. Перерыв: ||14:00 - 15:00||
5. Закрытие: ||15:00 - 16:00||

||Сюрприз в конце!||
```

**Как будет выглядеть:**
- Каждое время будет скрыто отдельно
- Пользователь может открыть каждое время независимо
- "Сюрприз в конце!" также будет скрыт

### Пример 4: Спойлер с форматированием

**Текст для рассылки:**
```
🎊 **ВАЖНОЕ ОБЪЯВЛЕНИЕ!**

Основная информация видна всем.

||**Секретная информация:**
• Пароль для входа: 12345
• Код доступа: ABC123
• Контакт организатора: +7 (999) 123-45-67||
```

**Как будет выглядеть:**
- Основной текст виден сразу
- Вся секретная информация (с форматированием) будет скрыта
- При открытии спойлера форматирование сохранится

### Пример 5: Спойлер в середине предложения

**Текст для рассылки:**
```
Приглашаем на мероприятие ||15 декабря в 18:00|| в главном корпусе.
```

**Как будет выглядеть:**
- Предложение видно, но дата и время скрыты
- При нажатии откроется "15 декабря в 18:00"

### Пример 6: Многострочный спойлер

**Текст для рассылки:**
```
Дорогие друзья!

||Внимание! Секретная информация:

1. Приходите за 30 минут до начала
2. Принесите документы
3. Дресс-код: вечерний
4. Парковка бесплатная||

Ждем вас!
```

**Как будет выглядеть:**
- Весь блок с секретной информацией будет скрыт
- При открытии спойлера откроется весь многострочный текст

## Как протестировать спойлеры

### Шаг 1: Используй команду `/broadcast_test`

Отправь команду с текстом, содержащим спойлеры:

```
/broadcast_test Привет! Это обычный текст, а вот ||это скрыто||
```

### Шаг 2: Проверь результат

Бот отправит тебе тестовое сообщение, где ты увидишь:
- Как будет выглядеть сообщение у получателей
- Как работает спойлер (затемненная область)
- Какой формат используется (Markdown или HTML)

### Шаг 3: Если всё правильно - запускай рассылку

Используй команду `/broadcast` для реальной рассылки.

## Пошаговая инструкция для рассылки со спойлерами

### Вариант 1: Текстовая рассылка

1. **Отправь команду:**
   ```
   /broadcast
   ```

2. **Выбери тип рассылки:**
   - Нажми "📝 Текстовое сообщение"

3. **Введи текст со спойлерами:**
   ```
   🎉 Важное объявление!
   
   Дата: 15 декабря
   Время: ||18:00||
   Место: ||Главный корпус||
   
   ||Секретная информация будет здесь||
   ```

4. **Проверь предпросмотр:**
   - Бот покажет, как будет выглядеть сообщение
   - Убедись, что спойлеры на месте

5. **Подтверди рассылку:**
   - Нажми "✅ Отправить всем"

### Вариант 2: Фото с подписью

1. **Отправь команду:**
   ```
   /broadcast
   ```

2. **Выбери тип рассылки:**
   - Нажми "🖼 Фото с подписью"

3. **Загрузи фото**

4. **Введи подпись со спойлерами:**
   ```
   🎊 Афиша мероприятия!
   
   Дата: ||15 декабря||
   Время: ||18:00||
   
   ||Дополнительная информация||
   ```

5. **Проверь предпросмотр и подтверди**

## Важные замечания

### ✅ Что работает:

- ✅ Несколько спойлеров в одном сообщении
- ✅ Многострочные спойлеры
- ✅ Комбинация спойлеров с другим форматированием (**жирный**, *курсив*)
- ✅ Спойлеры в подписях к фото
- ✅ Автоматическое определение и конвертация

### ⚠️ Ограничения:

- ⚠️ Не используй `||` внутри спойлера (это сломает форматирование)
- ⚠️ Спойлеры автоматически конвертируются в HTML формат
- ⚠️ Максимальная длина сообщения: 4096 символов
- ⚠️ Максимальная длина подписи: 1024 символа

### 💡 Советы:

1. **Всегда тестируй** перед рассылкой с помощью `/broadcast_test`
2. **Используй спойлеры умеренно** - слишком много скрытого текста может раздражать
3. **Делай спойлеры информативными** - пользователь должен понимать, зачем открывать спойлер
4. **Комбинируй с эмодзи** для привлечения внимания: `||🎁 Сюрприз!||`

## Частые вопросы (FAQ)

### Q: Можно ли использовать спойлеры в обычных сообщениях?

**A:** Да! Спойлеры работают во всех типах рассылок:
- Текстовые сообщения (`/broadcast`)
- Фото с подписью (`/broadcast`)
- Отправка конкретному пользователю (`/send_to`)

### Q: Как проверить, что спойлеры работают?

**A:** Используй команду `/broadcast_test`:
```
/broadcast_test Текст с ||спойлером||
```

### Q: Можно ли вложить спойлер в спойлер?

**A:** Нет, вложенные спойлеры не поддерживаются. Используй один спойлер для всего блока.

### Q: Работают ли спойлеры в старых версиях Telegram?

**A:** Спойлеры поддерживаются в Telegram Desktop, iOS и Android с обновлениями 2023 года и новее. В старых версиях текст может отображаться как обычный.

### Q: Можно ли использовать HTML теги `<spoiler>`?

**A:** Да! Бот автоматически распознает и HTML формат:
```
<spoiler>скрытый текст</spoiler>
```

Но проще использовать Markdown формат: `||текст||`

## Технические детали

### Как это работает:

1. Бот автоматически определяет наличие спойлеров `||текст||`
2. Конвертирует их в HTML формат `<spoiler>текст</spoiler>`
3. Отправляет сообщение с `parse_mode="HTML"`
4. Telegram отображает спойлеры как затемненные области

### Автоматическая конвертация:

- `||текст||` → `<spoiler>текст</spoiler>`
- Весь текст конвертируется в HTML формат
- Markdown форматирование (**жирный**, *курсив*) также конвертируется в HTML
