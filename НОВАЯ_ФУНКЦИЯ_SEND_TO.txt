🎯 ЧТО ДОБАВЛЕНО?
───────────────────────────────────────────────────────────────────

Теперь ты как админ можешь отправлять файлы или картинки конкретному 
пользователю по его Telegram ID.

───────────────────────────────────────────────────────────────────
🚀 КАК ИСПОЛЬЗОВАТЬ?
───────────────────────────────────────────────────────────────────

СПОСОБ 1: Быстрый (30 секунд)
┌─────────────────────────────────────────────────────────────────┐
│ 1. /send_to 123456789                                           │
│ 2. [Загрузи файл или картинку]                                  │
│ 3. Добавь подпись или отправь /skip                             │
│ 4. ✅ Готово!                                                    │
└─────────────────────────────────────────────────────────────────┘

СПОСОБ 2: Пошаговый
┌─────────────────────────────────────────────────────────────────┐
│ 1. /send_to                                                     │
│ 2. Введи Telegram ID получателя                                │
│ 3. [Загрузи файл или картинку]                                 │
│ 4. Добавь подпись или /skip                                     │
│ 5. ✅ Готово!                                                    │
└─────────────────────────────────────────────────────────────────┘

ОТМЕНА В ЛЮБОЙ МОМЕНТ:
┌─────────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────────┘

───────────────────────────────────────────────────────────────────
📋 ЧТО МОЖНО ОТПРАВЛЯТЬ?
───────────────────────────────────────────────────────────────────

✅ 🖼 Фото (JPG, PNG и т.д.)
✅ 📄 Документы (PDF, DOC, XLS, ZIP и т.д.)
✅ 🎥 Видео (MP4, AVI, MOV и т.д.)
✅ 🎵 Аудио (MP3, WAV, OGG и т.д.)

───────────────────────────────────────────────────────────────────
💡 ПРИМЕРЫ
───────────────────────────────────────────────────────────────────

📸 Отправить фото с текстом:
   /send_to 123456789
   [Фото]
   Привет! Вот твоя картинка 🎨

📄 Отправить PDF без подписи:
   /send_to 987654321
   [PDF файл]
   /skip

───────────────────────────────────────────────────────────────────
🆕 НОВЫЕ КОМАНДЫ
───────────────────────────────────────────────────────────────────

/send_to [id]  - Отправить файл пользователю
/cancel        - Отменить текущий процесс
/help          - Справка (покажет все твои админские команды)

───────────────────────────────────────────────────────────────────
🛡️ БЕЗОПАСНОСТЬ
───────────────────────────────────────────────────────────────────

✅ Доступ только для админов (проверка по ADMIN_IDS в .env)
✅ Проверка существования пользователя в базе данных
✅ Валидация формата Telegram ID
✅ Проверка длины подписи (максимум 1024 символа)
✅ Логирование всех отправок в bot.log
✅ Обработка ошибок (бот заблокирован, неверный ID и т.д.)

───────────────────────────────────────────────────────────────────
✨ ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ
───────────────────────────────────────────────────────────────────

• Бот проверяет, есть ли пользователь в БД и показывает его ФИО
• Можно отправлять файлы даже тем, кого нет в БД (по ID)
• Поддержка Markdown в подписях (**жирный**, *курсив*, `код`)
• Подробные сообщения об ошибках с подсказками
