# 🎨 Руководство по настройке дизайна билетов

## 📁 Структура файлов

```
project/
├── ticket_template.png        # Ваш шаблон билета (фон)
├── ticket_config.py           # Настройки координат и шрифтов
└── tasks.py                   # Генератор билетов (не трогайте)
```

---

## 🖼️ Шаг 1: Загрузите свой шаблон

1. Подготовьте изображение билета в формате PNG или JPG
2. Назовите файл `ticket_template.png`
3. Загрузите на сервер в корень проекта

```bash
# На сервере:
cd ~/tg_bot_bpl
# Загрузите файл через scp или другим способом
```

---

## ⚙️ Шаг 2: Настройте координаты в `ticket_config.py`

Откройте файл `ticket_config.py` и измените координаты:

### 📍 Координаты текста (x, y)

```python
TEXT_POSITIONS = {
    'fio': (100, 150),              # ФИО основного участника
    'faculty': (100, 220),          # Факультет
    'course': (100, 280),           # Курс обучения
    'group': (100, 340),            # Группа
    'student_id': (100, 400),       # Студенческий билет / Диплом
    'ticket_type': (100, 460),      # Одиночный/Парный
    'partner_fio': (100, 520),      # ФИО партнёра (если есть)
}
```

**Как найти координаты?**
- Откройте `ticket_template.png` в графическом редакторе (Photoshop, GIMP, даже Paint)
- Наведите курсор на нужное место
- Посмотрите координаты в правом нижнем углу
- x = горизонтальное смещение (слева направо)
- y = вертикальное смещение (сверху вниз)

---

### 🔤 Размеры шрифтов

```python
FONT_SIZES = {
    'fio': 50,          # ФИО - основной текст
    'info': 35,         # Группа, факультет и т.д.
    'small': 25,        # Мелкий текст (партнёр)
}
```

Измените цифры чтобы текст подходил по размеру.

---

### 🎨 Цвета текста

```python
TEXT_COLORS = {
    'default': 'black',       # По умолчанию
    'fio': 'black',           # Цвет ФИО
    'info': 'black',          # Цвет доп. информации
    'partner': '#555555',     # Цвет текста партнёра (серый)
}
```

Можно использовать:
- Названия: `'black'`, `'white'`, `'red'`, `'blue'`
- HEX-коды: `'#FF0000'` (красный), `'#00FF00'` (зеленый)
- RGB-кортежи: `(255, 0, 0)` (красный)

---

### 📱 QR-код

```python
QR_CONFIG = {
    'size': (200, 200),         # Размер QR-кода (ширина, высота)
    'position': (950, 320),     # Позиция QR-кода (x, y)
    'box_size': 10,             # Детализация QR (больше = крупнее "пиксели")
    'border': 2,                # Толщина белой рамки вокруг QR
}
```

## 🧪 Шаг 3: Тестирование

### Локально (на своём компьютере):

```bash

pip install pillow qrcode

# Создайте тестовый скрипт
python -c "
from PIL import Image, ImageDraw, ImageFont
```

### На сервере:

```bash

docker-compose stop celery_worker bot

# 2. Пересоберите с новым конфигом
docker-compose build celery_worker bot

# 3. Запустите
docker-compose up -d

# 4. Протестируйте генерацию одного билета
docker-compose exec celery_worker python -c "
from tasks import generate_ticket
# Создайте тестовые данные...
"
```

## 💡 Советы

1. **Используйте высококачественный шаблон** - минимум 1200x600 пикселей
2. **Оставляйте отступы** - текст не должен быть впритык к краям
3. **Контрастные цвета** - текст должен быть хорошо виден на фоне
4. **QR-код** - минимум 150x150 пикселей, максимум 300x300
5. **Тестируйте** - сгенерируйте несколько тестовых билетов перед массовой рассылкой

## 🔧 Дополнительные настройки

### Изменить шрифт:

```python
# В ticket_config.py
FONT_PATH = "/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf"
```

Доступные шрифты на сервере:
```bash
fc-list | grep ttf
```

### Формат данных в QR-коде:

```python
QR_DATA_FORMAT = "TICKET_{user_id}_{telegram_id}"
```

Доступные переменные:
- `{user_id}` - ID в базе данных
- `{telegram_id}` - Telegram ID пользователя
- `{fio}` - ФИО
- `{student_id}` - Номер студ. билета

## ❓ Частые проблемы

### Текст обрезается или не помещается

- Уменьшите размер шрифта в `FONT_SIZES`
- Проверьте координаты - возможно текст за краем изображения

### QR-код не виден

- Увеличьте `size` в `QR_CONFIG`
- Проверьте что `position` не за краем шаблона
- Убедитесь что фон под QR светлый

### Шрифт не подходит

- Измените `FONT_PATH` на другой шрифт
- Загрузите свой .ttf файл и укажите путь к нему
