# 🔐 Команды администратора

## 📊 Статистика и мониторинг

### `/stats`
Показывает статистику регистрации:
- Количество зарегистрированных пользователей
- Оставшиеся места
- Процент заполнения
- Статус регистрации (открыта/закрыта)

```
/stats
```

---

### `/tickets_status`
Подробный статус билетов:
- Сколько билетов сгенерировано
- Сколько разослано
- Сколько готово к отправке
- Примеры проблемных записей

```
/tickets_status
```

---

### `/tickets_count`
Подсчет файлов билетов:
- Количество файлов в папке tickets/
- Размер папки
- Количество записей в БД

```
/tickets_count
```

---

## 🎫 Управление билетами

### `/generate_tickets`
Генерация всех билетов для зарегистрированных пользователей:
- Автоматический мониторинг прогресса
- Обновления каждые 400 билетов
- Финальная статистика

```
/generate_tickets
```

---

### `/rass`
Рассылка готовых билетов пользователям:
- Отправляет только неотправленные билеты
- Можно запускать повторно (безопасно)
- Мониторинг прогресса каждые 100 билетов
- Подробная финальная статистика

```
/rass
```

---

### `/test_rass`
Тестовая рассылка - отправляет 10 случайных билетов в текущий чат:
- Для проверки перед основной рассылкой
- Показывает ФИО и Telegram ID для каждого билета

```
/test_rass
```

---

### `/delete_ticket <telegram_id>`
Удаление билета конкретного пользователя:
- Удаляет файл билета
- Помечает билет как отмененный в БД
- Освобождает место

```
/delete_ticket 123456789
```

---

## 📤 Отправка файлов пользователям

### `/send_to [telegram_id]`
**НОВАЯ КОМАНДА** - Отправка файла или картинки конкретному пользователю:

**Использование:**
```
/send_to 123456789
```
или просто:
```
/send_to
```
(и ввести ID на следующем шаге)

**Что поддерживается:**
- 🖼 Фото (изображения)
- 📄 Документы (PDF, DOC, XLS, etc.)
- 🎥 Видео
- 🎵 Аудио

**Процесс:**
1. Введи Telegram ID
2. Отправь файл
3. Добавь подпись (или `/skip`)

**Отмена:**
```
/cancel
```

📚 Подробная инструкция: [SEND_TO_USER_GUIDE.md](./SEND_TO_USER_GUIDE.md)

## 📢 Массовая рассылка

### `/broadcast`
Интерактивная массовая рассылка всем пользователям:

**Типы:**
- 📝 Текстовое сообщение (до 4096 символов)
- 🖼 Фото с подписью (подпись до 1024 символов)

**Процесс:**
1. Выбери тип сообщения
2. Введи текст / загрузи фото
3. Добавь подпись (для фото)
4. Проверь preview
5. Подтверди отправку

**Скорость:** ~18 сообщений/секунду (лимит Telegram)

```
/broadcast
```

📚 Подробная инструкция: [BROADCAST_README_RU.md](./BROADCAST_README_RU.md)

---

### `/broadcast_test <текст>`
Тестовая рассылка - отправляет сообщение только тебе:
- Для проверки форматирования
- Поддерживает Markdown

```
/broadcast_test Привет! Это **тестовое** сообщение.
```

## 📊 Экспорт данных

### `/create_google_shit`
Экспорт данных регистрации в Google Sheets:
- Создает два листа: solo и duo
- Разделяет участников по типу билета
- Статистика экспорта

**Требования:**
- Google Sheets API включен
- Файл `credentials.json` в корне проекта
- ID таблицы в `.env` (`GOOGLE_SHEET_ID`)

```
/create_google_shit
```

## 🎯 Быстрая справка

| Команда | Что делает | Когда использовать |
|---------|------------|-------------------|
| `/stats` | Статистика регистрации | Проверить заполненность |
| `/tickets_status` | Статус билетов | Проверить прогресс генерации/рассылки |
| `/generate_tickets` | Генерация билетов | После завершения регистрации |
| `/rass` | Рассылка билетов | После генерации билетов |

| `/delete_ticket` | Удалить билет | Отменить регистрацию пользователя |

## 💡 Типичный workflow

### Генерация и рассылка билетов

```bash
1. /tickets_status          # Проверка текущего статуса
2. /generate_tickets        # Генерация всех билетов
3. /tickets_status          # Проверка после генерации
4. /test_rass              # Тест на 10 билетах (опционально)
5. /rass                   # Полная рассылка
6. /tickets_status         # Финальная проверка
```

### Массовая рассылка объявления

```bash
1. /broadcast_test Текст    # Тест форматирования (опционально)
2. /broadcast              # Запуск интерактивной рассылки
3. Следуй инструкциям бота
```

### Отправка файла конкретному пользователю

```bash
1. /send_to 123456789      # ID пользователя
2. [Загрузить файл]
3. Добавить подпись или /skip
```

## 📝 Настройка админов

Добавь Telegram ID администраторов в `.env`:

```env
ADMIN_IDS=123456789,987654321,555555555
```

Можно указать несколько ID через запятую.

**Как узнать свой Telegram ID?**
- Используй бот [@userinfobot](https://t.me/userinfobot)
- Или напиши `/start` в боте - он покажет твой ID в логах
